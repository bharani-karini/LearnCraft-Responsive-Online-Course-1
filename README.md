# LearnCraft-Responsive-Online-Course-1
🎓 LearnCraft – Responsive Online Course Website
📌 Project Overview

LearnCraft is a modern and responsive online learning website developed as a mini web development project using HTML5 and CSS3. It provides a simple and attractive platform for students to explore online courses, discover learning opportunities, and improve their skills.

✨ Features
🏠 Attractive homepage with modern navigation.
📚 Different course categories.
🎯 Popular courses with descriptions and details.
👨‍🏫 Instructor profiles.
⭐ Student reviews and testimonials.
📝 Course enrollment options.
📱 Responsive design for desktop and mobile devices.
🎨 Clean and user-friendly interface.
🛠️ Technologies Used
HTML5 – Website structure.
CSS3 – Styling and responsive design.
